# Otobisi Monorepo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert Otobisi into a pnpm + Turborepo monorepo with three Nuxt 4 apps (`web`, `admin`, `super-admin`), each with its own dev server, sharing two Nuxt layers.

**Architecture:** `apps/*` are Nuxt apps that `extends: ["@otobisi/ui", "@otobisi/core"]`. `layers/ui` holds shared components/CSS/Tailwind; `layers/core` holds modules, i18n, shared composables. Mirrors `D:\Studying\Not Done Projects\StoreOS\storeos`.

**Tech Stack:** Nuxt 4.5, pnpm 10.28.1, Turborepo 2, Tailwind 3, @nuxtjs/i18n 10, Pinia 4, @nuxtjs/supabase.

**Spec:** `docs/superpowers/specs/2026-09-29-monorepo-design.md`

## Global Constraints

- Scope `@otobisi/*`; layers `@otobisi/core`, `@otobisi/ui`; apps `@otobisi/web|admin|super-admin`.
- Ports: web 3000, admin 3001, super-admin 3002 (`nuxt dev --port=N`).
- `typescript.typeCheck: false` must stay (path has spaces); do not add a `lint` that runs vue-tsc.
- `packageManager: pnpm@10.28.1`; `.npmrc` has `shamefully-hoist=false`, `strict-peer-dependencies=false`, `auto-install-peers=true`.
- Keep current dependency versions (nuxt ^4.5.2, pinia ^4.0.3, @pinia/nuxt ^1.0.2, etc.).
- Components auto-import with `pathPrefix: false`, including those from layers (use `${currentDir}/components`).
- Never use the `~` alias inside `layers/**`: in a layer `~` resolves to the consuming app. Use relative imports.
- Colors via `surface.*`/`text.*`/`border.*` Tailwind classes; dark mode is class-based.
- Use `git mv` for moves so history is kept. Commit trailer: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.

## Deviation from spec (deliberate)

`useToast` goes to `@otobisi/ui` (not core): it is coupled to `VToast` and its types, and a `core -> ui` import would create a cross-layer dependency. `useTheme` and `useLocaleSwitch` go to core as specified.

## Review Focus

- `~/` imports left inside `layers/**` (they resolve to the wrong srcDir): expected none; grep in Task 3.
- Web files still importing `~/types/shared/*` after the types move: expected rewritten; grep in Task 3.
- Tailwind classes used only in layer components missing from built CSS (e.g. `bg-surface-1`, `icon-*` safelist): expected present; check in Task 4.
- No-flash dark-mode script and `/en` + `/ar` prefixed routes working in every app, not just web: curl check in Tasks 4 and 5.
- Three dev servers running at once without port or `.nuxt` collisions, from a path containing spaces: Task 5.
- i18n locale merging between core and web (files from both layers loaded): Task 4, fallback documented.
